DeltaCrop transforms traditional crop growth models using differentiable programming to bridge process-based modeling with machine learning. We're making the widely-used WOFOST model differentiable, enabling more efficient training and better integration with AI for improved food security predictions. This project is funded by the Netherlands eScience Center and runs from 2025-2027.
